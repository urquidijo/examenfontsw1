Ruta de configuración

Sigue estos pasos para dejar el proyecto listo para operar.

1 Inicio

Usuarios y trámites

Primero define quién participa en el proyecto y qué trámites se gestionarán.

2 Organización

Departamentos

Luego crea las áreas o departamentos que participarán dentro del flujo de trabajo.

3 Diseño

Workflows

Cuando ya tengas usuarios, trámites y departamentos, diseña el flujo de trabajo del proyecto.

4 Operación

Tickets y tareas

Finalmente administra la operación diaria con tickets y tareas vinculadas al flujo ya configurado.
