Cómo usar este módulo

Sigue este flujo para trabajar de forma ordenada.

1. Crea un workflow

Registra el nombre y una breve descripción del flujo que vas a construir.

2. Diseña el flujo

Entra al diseñador para agregar nodos, conexiones y responsables dentro del proceso.

3. Publica cuando esté listo

Usa “Poner en producción” cuando el workflow ya esté terminado y validado.

4. Vuelve a desarrollo si necesitas cambios

Un workflow publicado puede volver a modo desarrollo para seguir ajustándolo.
